# Ancient Philosophy as a Way of Life — Website

A static, GitHub Pages-ready website in the Slate & Limestone color palette.

## Files
- `index.html` — website homepage and navigation
- `images/` — seven local historical images used by the website
- `materials/` — 14 original, unmodified PDF files, each linked on the materials page
- `All_Game_Materials.zip` — the 14 PDFs bundled for convenient downloading
- `PREVIEW_OFFLINE.html` — self-contained visual preview (images embedded) that uses the same relative PDF links

## Test locally
Extract the ZIP. Open `index.html` or `PREVIEW_OFFLINE.html` from the extracted folder in a browser. Keep the `materials` directory next to the HTML files so every PDF link works.

## Publish on GitHub Pages
Upload `index.html`, `images`, `materials`, and `All_Game_Materials.zip` to the repository root. GitHub Pages serves this static site without a build step. `PREVIEW_OFFLINE.html` is optional when publishing.

## Notes
- All 14 PDFs have been copied byte-for-byte from the provided files. The typo in the supplied filename “Epciurean Faction Handout.pdf” has been corrected only in the website’s link filename and label.
- Original source and reuse licenses of the supplied images should be verified before public publication.
